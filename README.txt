GITHUB PAGES PAR PHONE SE LAGANA
1. Zip ko phone me Extract karein (Files app -> zip par tap -> Extract).
2. github.com me login -> naya repository banayein (Public).
3. "Add file" -> "Upload files" -> extract hui SAARI files select karein -> "Commit changes".
4. Repository -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: /(root) -> Save.
5. 1-2 minute baad link milega: https://USERNAME.github.io/REPO-NAME/
6. Link ko Chrome me kholein -> menu -> "Install app" / "Add to Home screen".
   Ek baar khulne ke baad internet band karke bhi chalega.
   iPhone: Safari -> Share -> Add to Home Screen.

Update karna ho to nayi files wahi upload karein (same naam se). App 2 baar kholne par naya version le leta hai.

Bina GitHub ke: index.html ko seedha Chrome me kholein - ye bhi offline chalta hai.

Data usi phone/browser me save hota hai. More -> Settings -> Data Backup & Restore se backup file zarur rakhein.
